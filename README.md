# V4NT Platform

Plataforma de inteligência e operação comercial para empresas B2B. Interface em português do Brasil, valores em reais e fuso padrão America/Sao_Paulo.

## Acompanhar o desenvolvimento

- [Cronograma e critérios de entrega](docs/cronograma.md)
- [Auditoria inicial e arquitetura](docs/missoes/01-arquitetura.md)

Cada missão tem um relatório com o que foi implementado, testes, evidências e pendências. O cronograma indica a ordem das entregas. As funcionalidades previstas passam a estar disponíveis conforme os respectivos relatórios de validação.
